#Odin Recipes
Учебный проект в рамках курса TOP (раздел Foundations)

##Описание
Простой сайт с коллекцией рецептов, состоящий из главной страницы со списком рецептов и отдельных  HTML-страниц для каждого блюда.

###Навыки
-Работа с Git и GitHub (создание репозитория, коммиты, пуш)
-Структурирование HTML-документов
-Работа с файловой системой через командную строку
